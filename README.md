# 뭉타이머 7일 완성 🌱

코틀린과 안드로이드 개발을 처음 배우는 사람이 **7일 동안** 공부 타이머 앱 「뭉타이머」를
안드로이드 스튜디오 + 코틀린(Jetpack Compose)으로 직접 만들 수 있게 안내하는 **학습용 웹사이트**입니다.

## 여는 방법

`index.html` 파일 하나가 전부입니다. 서버도 인터넷도 필요 없습니다.

- 저장소를 내려받아 `index.html`을 더블클릭해 브라우저로 엽니다.
- 또는 저장소 Settings → Pages에서 이 브랜치를 게시하면 주소로 접속할 수 있습니다.

## 구성

| 메뉴 | 내용 | 그날 만드는 것 |
| --- | --- | --- |
| 시작하기 전에 | 준비물, 7일 로드맵, 범위를 줄인 부분과 이유 | – |
| Day 1 | 코틀린 기초 (변수, 타입, 조건문, 반복문, 함수, null 안전성) | 시간 표시 · 30분 판단 함수 |
| Day 2 | 코틀린 핵심 (클래스, data class, enum, 컬렉션, 람다) | 뭉 데이터 모델과 등급 enum |
| Day 3 | 안드로이드 스튜디오와 Compose 기초 | 타이머 화면 UI |
| Day 4 | 상태 관리와 코루틴 (ViewModel, StateFlow) | 백그라운드에서도 정확한 타이머 |
| Day 5 | 확률 로직 + Room | 뭉 뽑기와 뭉 도감 |
| Day 6 | Firebase (익명 로그인, Firestore) | 그룹, 초대 코드, 랭킹, 대표 뭉 |
| Day 7 | Navigation 3, 테마, 버그 수정, APK | 앱 완성 |

모든 Day는 **오늘의 목표 → 개념 설명 → 예제 코드 → 안드로이드 스튜디오 사용법 → 복습 퀴즈 → 오늘의 과제**
순서이며, 과제에는 요구사항 체크리스트 · 힌트 · 접어 둔 모범 답안이 있습니다.
완료한 일차, 퀴즈 점수, 과제 체크는 브라우저의 localStorage에 저장됩니다.

## 코드를 어디까지 확인했나

2026년 11월 기준 최신 안정 버전(AGP 9.5.1, Kotlin 2.4.21, Compose BOM 2026.09.00, Room 3.0.3,
Firebase BoM 35.1.0, Navigation 3 1.2.1)으로 확인했습니다.

- 순수 코틀린 예제와 과제 답안: 실행해서 사이트에 적힌 실행 결과와 대조
- Day 3 ~ Day 7 각 날짜가 끝난 시점의 앱 전체: 실제 안드로이드 프로젝트로 빌드 (컴파일 경고 0개)
- Room 저장/조회, 꺼졌다 켜진 타이머의 복원, 종료 → 뽑기 → 도감 갱신, 탭 이동과 뒤로 가기:
  컴퓨터 위의 테스트 환경(Robolectric)에서 실행
- **확인하지 못한 것**: 실제 폰/에뮬레이터에서의 모습, Firebase 서버와 주고받는 동작
  (Firebase 프로젝트가 있어야 해서 컴파일까지만 확인)

## 고쳐 쓰기

`index.html`은 위에서부터 CSS → 앱 껍데기 → 페이지별 콘텐츠(`<template id="page-day1">` …) → JS 순서입니다.
본문과 코드는 템플릿 안에 그대로 들어 있어, 텍스트 편집기로 열어 바로 고칠 수 있습니다.
